## Overview

BlueJ is a free Java development environment designed for beginners, used by millions of people worldwide ([BlueJ team](https://www.bluej.org/)). It is an integrated development environment (IDE) for the Java programming language, built mainly for education but also suitable for small-scale software development — and it is not the same thing as [Blue J](/organizations/blue-j/), the unrelated Toronto legal-technology company whose similar name causes regular confusion.

BlueJ began in 1998–99 at Monash University in Australia, as a Java port of Blue, the teaching language and environment Michael Kölling had built for his PhD work ([BlueJ team](https://www.bluej.org/about.html)). It is now maintained by a team at King's College London, where Kölling is Professor of Computer Science ([King's College London](http://kcl.ac.uk/news/bluej-meeting-the-programming-scale-up-challenge-with-bluej)). Over more than 25 years it has grown from a teaching experiment into one of the most widely used educational programming tools in the world: King's estimates that more than 20 million learners have used it, with 2 million new users every year ([King's College London](http://kcl.ac.uk/news/bluej-meeting-the-programming-scale-up-challenge-with-bluej)).

## From Blue to BlueJ: Monash, 1998–1999

BlueJ's predecessor was Blue, an integrated system comprising an object-oriented language and an object-oriented development environment, developed specifically for teaching object-oriented programming to beginners; its implementation language was C++, and it ran only on Solaris and Linux — a port to Windows was never completed ([Michael Kölling and John Rosenberg](https://kar.kent.ac.uk/13735/1/BlueJMike.pdf_nocoversheet)). BlueJ provides "an almost identical environment to Blue, but with Java as the supported language", as a complete re-implementation in Java that made it cross-platform ([Michael Kölling and John Rosenberg](https://kar.kent.ac.uk/13735/1/BlueJMike.pdf_nocoversheet)).

The work was done by Michael Kölling and John Rosenberg at Monash University in Melbourne, Australia ([Michael Kölling and John Rosenberg](https://kar.kent.ac.uk/13735/1/BlueJMike.pdf_nocoversheet)). Kölling dates the BlueJ project itself to 1998, calling it "a direct copy of its predecessor system, Blue, this time with Java as the supported language" ([Michael Kölling](https://kar.kent.ac.uk/23972/1/BlueJMike.pdf_nocoversheet)), and the environment was first released in 1999 ([BlueJ team](https://www.bluej.org/about.html)). It was first used at Monash in 1999, where students surveyed about the course found it helpful — particularly the object bench and the way compiler error messages were integrated with the source editor ([Michael Kölling](https://kar.kent.ac.uk/23972/1/BlueJMike.pdf_nocoversheet)). Generous support from Sun Microsystems, and more recently Oracle, has funded its development ever since ([BlueJ team](https://www.bluej.org/about.html)).

## Designed for teaching, not for professionals

BlueJ was designed around three explicit goals: to make the environment truly object-oriented by representing objects and classes as first-class entities in the user interface; to allow interaction with individual objects to encourage small-scale experimentation; and to simplify the interface so it presents minimal distraction from the principles of programming ([Michael Kölling](https://kar.kent.ac.uk/23972/1/BlueJMike.pdf_nocoversheet)). The contrast was deliberate: most environments were built for professional programmers, "and the complexity of their tools overwhelms beginners" ([Michael Kölling](https://kar.kent.ac.uk/23972/1/BlueJMike.pdf_nocoversheet)).

Open a project and the main window shows a UML class diagram of the application's structure; right-clicking a class lets you run a constructor, which creates an object that appears on the object bench, where any of its public methods can be executed and its state inspected ([Michael Kölling](https://kar.kent.ac.uk/23972/1/BlueJMike.pdf_nocoversheet)). Classes can be compiled individually, methods can be called on live objects with their return values displayed, and the editor highlights nested blocks in different colours so the scope of a method or loop is visible at a glance ([InfoWorld](https://www.infoworld.com/article/2257804/bluej-and-greenfoot-the-best-ides-to-learn-java.html)). More advanced features are "revealed as users come to them", in the words of lead developer Neil Brown ([InfoWorld](https://www.infoworld.com/article/2257804/bluej-and-greenfoot-the-best-ides-to-learn-java.html)). The environment also has an integrated debugger, integrated JUnit testing — interactive test sessions can be recorded and replayed as JUnit test methods — and an extension interface for third-party tools ([Michael Kölling](https://kar.kent.ac.uk/23972/1/BlueJMike.pdf_nocoversheet)). "BlueJ is designed specifically for beginners," Kölling wrote. "The central aim is that we want to teach about OO programming, not about using a particular environment" — students, he reported, could use it competently after the first half hour of the first tutorial ([Michael Kölling](https://kar.kent.ac.uk/23972/1/BlueJMike.pdf_nocoversheet)).

## The objects-first pedagogy

BlueJ was never just a tool; it was an argument about how programming should be taught. Kölling's premise was that teaching object orientation is not intrinsically harder than teaching procedural programming — it is made harder by a lack of appropriate tools and pedagogical experience ([Michael Kölling](https://kar.kent.ac.uk/23972/1/BlueJMike.pdf_nocoversheet)). His chapter sets out five guidelines for an introductory course: objects first, from day one; don't start with a blank screen; teach code reading explicitly; use "large", multi-class projects; and show program structure — with corollaries including "don't start with 'main'" and "don't use 'Hello World'", which teaches nothing about objects ([Michael Kölling](https://kar.kent.ac.uk/23972/1/BlueJMike.pdf_nocoversheet)).

The honest history is that the pedagogy travelled more slowly than the tool. "We published BlueJ, and after some time it received a reasonable amount of visibility and attention. Some institutions started using it. At first, we were delighted to see our system being used, then we were horrified," Kölling wrote: teachers were using BlueJ but still introducing material in exactly the same order as before, appreciating the simpler interface while ignoring the visualisation and interaction that were most of the point ([Michael Kölling](https://kar.kent.ac.uk/23972/1/BlueJMike.pdf_nocoversheet)). The team responded with workshops at universities and conferences, and — decisively — with a textbook: in late 2002, Objects First with Java, written with David Barnes, was published to carry the approach in full ([Michael Kölling](https://kar.kent.ac.uk/23972/1/BlueJMike.pdf_nocoversheet)). The book's seventh edition was published by Pearson in June 2025 ([Pearson](https://www.pearson.com/en-us/subject-catalog/p/objects-first-with-java-a-practical-introduction-using-bluej/P200000010666/9780138087173)), and the BlueJ team says it has sold hundreds of thousands of copies worldwide ([BlueJ team](https://www.bluej.org/)).

## What the evidence showed

Adoption grew steadily: more than 600 colleges and universities were using BlueJ by 2006 ([eWeek](https://www.eweek.com/development/sun-releases-netbeans-version-for-beginners/)), more than 800 universities by 2008 ([Michael Kölling](https://kar.kent.ac.uk/23972/1/BlueJMike.pdf_nocoversheet)), and by 2022 King's College London reported it implemented by thousands of institutions worldwide, attracting 2 million new users every year ([King's College London](http://kcl.ac.uk/news/bluej-meeting-the-programming-scale-up-challenge-with-bluej)). A 2002 study by Madden and Chambers found 70% of students rated BlueJ easy to use, against 39% for the professional environment JBuilder ([Michael Kölling](https://kar.kent.ac.uk/23972/1/BlueJMike.pdf_nocoversheet)). But Kölling is candid about the limits of that evidence: "I am not aware of any serious study into the effects of BlueJ on learning that included meaningful indicators, such as a control group or properly set up evaluations" ([Michael Kölling](https://kar.kent.ac.uk/23972/1/BlueJMike.pdf_nocoversheet)). The case for BlueJ rests on adoption, teacher feedback and the design argument — not on a controlled trial, and this profile does not pretend otherwise.

## Free, then open: the 2009 decision

For its first decade BlueJ was free to download but closed-source, and the team debated opening it "probably about once every year" since 1999 ([Michael Kölling](https://blogs.kcl.ac.uk/proged/2009/03/08/bluej-and-greenfoot-open-source-why-now/)). The objection was always the same: keeping the experience simple for beginners meant refusing most feature requests, and an open codebase risked forks — "similar to the Emacs/XEmacs split" — that would confuse students and swamp a very small team with support work ([Michael Kölling](https://blogs.kcl.ac.uk/proged/2009/03/08/bluej-and-greenfoot-open-source-why-now/)). In March 2009 the balance tipped: the brand was now well enough known that users would find the official version, and open sourcing gave adopting institutions security that the system could not disappear, let instructors use the source for software-engineering projects, and let Linux distributions include it ([Michael Kölling](https://blogs.kcl.ac.uk/proged/2009/03/08/bluej-and-greenfoot-open-source-why-now/)). The project became free and open source software under the GPL, with the Classpath exception, and Opensource.com later described the shift as BlueJ going from "a closed-source project" to having its source "opened up to the world" ([Opensource.com](https://opensource.com/education/11/10/bluej-closed-open-interview-ian-utting)).

An earlier bridge to professional tools had come in September 2006, when Sun Microsystems, the NetBeans community and the University of Kent released the NetBeans IDE/BlueJ Edition — a free, open-source IDE giving students "a migration path" from educational tools to a full-featured professional environment ([eWeek](https://www.eweek.com/development/sun-releases-netbeans-version-for-beginners/)). James Gosling, the creator of Java, called the BlueJ–NetBeans collaboration "the hottest thing in tools right now", because it took learners "from novice stages to serious development" ([eWeek](https://www.eweek.com/development/sun-releases-netbeans-version-for-beginners/)). Gosling's verdict on BlueJ itself is quoted on the project's homepage: "One of my favourite IDEs out there is BlueJ" ([BlueJ team](https://www.bluej.org/)).

## Stride, Greenfoot and the research the tool generates

BlueJ's younger sibling is Greenfoot, built on BlueJ by the same creator for younger users — from age 14 — as a simple Java IDE and animation framework for building games, organised around scenarios, worlds and actors ([InfoWorld](https://www.infoworld.com/article/2257804/bluej-and-greenfoot-the-best-ides-to-learn-java.html)). Stride, the frame-based programming language, was first developed for Greenfoot and then added to BlueJ as the headline feature of BlueJ 4.0 in March 2017, alongside Git support, JavaFX support, a tabbed editor and redesigned error reporting ([Michael Kölling](https://blogs.kcl.ac.uk/proged/2017/03/28/bluej-4-brings-a-bag-of-new-features/)). Stride is designed to combine the best of block-based and text programming: it works as a stepping stone towards text-based languages and as a comprehensive language in its own right ([Michael Kölling, Neil C. C. Brown, Hamza Hamza and Davin McCall](https://kclpure.kcl.ac.uk/ws/portalfiles/portal/109256610/SIGCSE_BlueJ_Stride.pdf)). Its frame-based editor removes the need for semicolons and guarantees brackets always match, so learners "won't grind to a halt because of small syntax errors" ([King's College London](http://kcl.ac.uk/news/bluej-meeting-the-programming-scale-up-challenge-with-bluej)). More than 125,000 learners had taken up Stride by 2022 ([King's College London](http://kcl.ac.uk/news/bluej-meeting-the-programming-scale-up-challenge-with-bluej)).

The tool also feeds research back into teaching. Where users permit it, BlueJ collects data on how learners respond to errors and get stuck; the team describes the resulting Blackbox database as "one of the world's largest available databases of programming tool interaction data", shared with other researchers and the basis of more than 20 papers by others ([King's College London](http://kcl.ac.uk/news/bluej-meeting-the-programming-scale-up-challenge-with-bluej)). BlueJ is still actively developed: version 6.0.1 was released on 4 September 2026, and it has shipped pre-installed on the Raspberry Pi since 2015 ([BlueJ team](https://www.bluej.org/); [InfoWorld](https://www.infoworld.com/article/2257804/bluej-and-greenfoot-the-best-ides-to-learn-java.html)).

## Not Blue J Legal

BlueJ must not be confused with Blue J, an unrelated Toronto legal-technology company founded in 2015 by [University of Toronto](/universities/university-of-toronto/) law professors that builds a generative-AI tax research platform and raised US$122 million in August 2025 ([University of Toronto](https://www.utoronto.ca/news/u-t-startup-blue-j-legal-raises-167-million-globe-and-mail)). The two share nothing but a similar name: one is a free Java environment for beginners that has been in classrooms since 1999; the other is a commercial AI tax product. The spelling is the tell — BlueJ is one word; Blue J Legal is two.

## Frequently asked questions

**What is BlueJ?** BlueJ is a free Java development environment designed for beginners, used by millions worldwide ([BlueJ team](https://www.bluej.org/)). It shows a project's classes as a UML-style diagram, lets students create objects and call their methods interactively, and is built for teaching object-oriented programming rather than professional software development ([Michael Kölling](https://kar.kent.ac.uk/23972/1/BlueJMike.pdf_nocoversheet)).

**Who created BlueJ?** Michael Kölling and John Rosenberg, at Monash University in Australia, building on Kölling's PhD work on the earlier Blue system ([Michael Kölling and John Rosenberg](https://kar.kent.ac.uk/13735/1/BlueJMike.pdf_nocoversheet)). The project is now maintained by a team at King's College London ([King's College London](http://kcl.ac.uk/news/bluej-meeting-the-programming-scale-up-challenge-with-bluej)).

**Is BlueJ free and open source?** Yes — free to download and use, and open source under the GPL with the Classpath exception since March 2009, after a decade as free but closed-source software ([Michael Kölling](https://blogs.kcl.ac.uk/proged/2009/03/08/bluej-and-greenfoot-open-source-why-now/)).

**What is Stride?** Stride is a frame-based programming language built into BlueJ since version 4.0 (2017) that combines the best of block-based and text programming ([Michael Kölling, Neil C. C. Brown, Hamza Hamza and Davin McCall](https://kclpure.kcl.ac.uk/ws/portalfiles/portal/109256610/SIGCSE_BlueJ_Stride.pdf)). It drops semicolons and guarantees matched brackets, easing the jump from blocks to text for school-age learners ([King's College London](http://kcl.ac.uk/news/bluej-meeting-the-programming-scale-up-challenge-with-bluej)).

**Is BlueJ the same as Blue J Legal?** No. BlueJ is a free Java IDE for beginners; Blue J is an unrelated Toronto company selling AI tax research to lawyers and accountants ([University of Toronto](https://www.utoronto.ca/news/u-t-startup-blue-j-legal-raises-167-million-globe-and-mail)).

## What this profile does not claim

This profile does not claim that BlueJ has been proven by controlled experiment to improve learning: its creator states that no serious controlled study existed as of 2008, and the evidence cited here is adoption, surveys and teacher feedback ([Michael Kölling](https://kar.kent.ac.uk/23972/1/BlueJMike.pdf_nocoversheet)). It does not repeat InfoWorld's compressed claim that BlueJ "first appeared in 1999, named simply Blue" — Blue was a separate earlier C++ system, and BlueJ was a Java re-implementation, not a rename ([Michael Kölling and John Rosenberg](https://kar.kent.ac.uk/13735/1/BlueJMike.pdf_nocoversheet)). It does not assert a JetBrains/Kotlin collaboration, which was not verified from a fully-read source, and mentions Kotlin only through the 6.0.1 release note ([BlueJ team](https://www.bluej.org/)). It does not state Greenfoot's adoption figures or release history, which were not researched in this pass.
