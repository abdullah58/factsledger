# Homepage stock imagery

The homepage uses two locally optimized stock images selected through the Manus image search workflow for relevant archive/research composition:

- `archive-shelves.jpg`: image-search result identified as an Unsplash library-research image.
- `research-desk.jpg`: image-search result identified as an Unsplash research image.

The images are used as editorial atmosphere only; they do not represent a specific FactsLedger profile, source, person, institution, or event. Alt text describes the visible scene rather than making a factual claim about the archive.
